# 구술 암기 퀴즈 (gabojago)

제2종 전기차량 운전면허 기능시험 구술 암기를 위한 10문제 랜덤 퀴즈 웹 애플리케이션입니다.

## 주요 기능

- **퀴즈 유형 선택**: 구구술(`6.1 ~ 6.81`), 신구술(`101 ~ 190`), 종합(`구구술 + 신구술`) 모드 지원
- **랜덤 10문제 & 60초 타이머**: 매 게임 중복 없이 무작위 10문제가 출제되며, 문제당 60초 제한 시간 제공
- **앞글자 힌트 및 원문 정답**: 답변 암기를 돕는 앞글자 힌트와 PDF 원문 기준 정답 확인 가능
- **자가 평가 및 복습**: 문항별로 암기 상태(`○ 완전암기`, `△ 부분암기`, `× 다시암기`)를 직접 평가하고 부족한 문항만 모아 재학습 가능
- **읽기/학습 설정**: 힌트 보기 ON/OFF 및 정답 글자 크기(보통 / 크게 / 더 크게) 조절 지원

## 프로젝트 구조

```text
public/
├── index.html   # 메인 HTML 구조
├── q.css        # UI 스타일시트
└── q.js         # 구술 문항 데이터 및 퀴즈 애플리케이션 로직
```
